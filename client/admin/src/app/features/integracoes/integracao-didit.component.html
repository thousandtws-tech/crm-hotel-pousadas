info Como funciona

  • Cada funcionário recebe um link hospedado (em Funcionários → Verificar) para fazer o KYC — documento + selfie.
  • O status chega pelo webhook (ou pelo botão Sincronizar) e aparece como badge na equipe.
  • Com “Exigir verificação” ligado, quem não aprovou fica na tela de verificação após o login — admin pode seguir em emergência.
  • Ambiente teste nunca bloqueia login — serve para homologar o fluxo com cenários de sandbox.
